# Prints da aplicação (CP2)

O README aponta para os arquivos desta pasta. Salve as capturas **com exatamente estes nomes**
(substituindo os prints antigos do CP1, que mostravam login Google/Apple).

| Arquivo                    | O que mostrar                                                                 |
| -------------------------- | ----------------------------------------------------------------------------- |
| `login.png`                | Tela de login (apenas e-mail e senha)                                         |
| `cadastro.png`             | Cadastro com foto, nome, e-mail, celular, nascimento, senha e confirmação     |
| `conversas.png`            | Lista com conversas individuais e grupos (selos "Individual" / "Grupo")       |
| `usuarios.png`             | Tela de usuários com a busca                                                  |
| `grupo-form.png`           | Criação/edição de grupo: foto, limite, vagas, política e integrantes          |
| `grupo-sem-vagas.png`      | Seleção de integrantes com o aviso "grupo sem vagas"                          |
| `chat-individual.png`      | Conversa individual com mensagens enviadas e recebidas                        |
| `chat-grupo.png`           | Conversa em grupo com nome do autor, menção (@) e mensagem "Para: Fulano"     |
| `integrantes.png`          | Lista de integrantes aberta pela foto do grupo                                |
| `perfil.png`               | Perfil aberto pela foto (e-mail, celular, nascimento)                          |
| `push-recebido.png`        | **Evidência**: notificação na bandeja do sistema com o app em segundo plano   |
| `push-api-log.png`         | Log da API na hospedagem (ou resposta `status: processed`) do mesmo envio     |
| `firestore.png`            | Firestore com `users`, `groups`, `directConversations` e `devices`            |
| `realtime-database.png`    | Realtime Database com `messages/` e `groupMembers/`                            |

## Como capturar

- **Aparelho físico** (obrigatório para o push): print padrão do sistema.
- **Android (emulador)**: botão de câmera na barra lateral, ou `Ctrl+S`.
- **iOS (simulador)**: `Cmd+S`.
